# ReminderBot
ReminderBot — Telegram-бот, который помогает не забывать о важных событиях: пользователь записывает дату, время и событие, а бот в нужный момент присылает напоминание.

# Назначение бота
Бот решает задачу личного планирования и напоминаний. Пользователь вводит событие с датой и временем, а бот берёт на себя роль «второй памяти»: хранит записи, показывает их и присылает уведомление в назначенный момент.

# Какие задачи решает пользователь
1. Записать событие — добавить напоминание с датой, временем и текстом.

2.Посмотреть список — узнать, какие события предстоят (на сегодня, на неделю, все).

3. Удалить или изменить — отменить ненужное напоминание или перенести его.

4. Получить напоминание — бот сам присылает сообщение в назначенное время.

5. Не забыть повторы — опционально: ежедневные, еженедельные напоминания.
